# asyncpp reference

## 목적

`asyncpp/asyncpp`를 C++20 coroutine 기반 비동기 처리에 활용하기 위한 외부
reference로 보관합니다. 이 라이브러리는 coroutine task, generator, promise,
동기화 primitive, dispatcher, thread pool, timer 등의 범용 유틸리티를
제공합니다. upstream 저장소는 [`repo`](repo)에 Git submodule로 연결합니다.

## 로컬 구성

- `repo`: `https://github.com/asyncpp/asyncpp`의 submodule
- `patches`: upstream에 적용할 로컬 patch
- `docs`: 통합 및 사용 과정에서 작성한 문서

## Patches

현재 patch는 없습니다. patch를 추가하면 적용 순서, 대상 upstream commit,
필요한 이유를 이 절에 기록합니다.
